===========================================================
DATABASE (PostgreSQL — ptw_database @ localhost)
===========================================================

Tables:
  users               — user accounts (username PK, password, name, role, department, email, ext)
  ptws                — permit records (id SERIAL PK, all PTW fields, JSONB[] for approvals/isolations)
  active_isolations   — currently active isolation locks (tag PK, linked_ptws TEXT[], primary_ptw, latest_ptw)
  risks               — risk assessment line items (title + date composite, hazard, effect, ctrl, eval, etc.)


===========================================================
KEY DATA FLOWS
===========================================================

CREATE PTW:
  Client WidgetPTW → POST /ptws → ptwDb.addPTWFromDict → INSERT ptws
  → optional: POST /ptws/attachments (multipart upload)

APPROVE PTW:
  Role window (Coordinator/Safety/DFGM/etc.) → POST /ptws/approvals
  → ptwDb.updatePTWApprovals → appends Approval to ptws.approvals[]
  → approval_status updated based on all votes

REQUEST RUN:
  Performer → POST /ptws/run-request → ptwDb.requestToRunPTW
  → running_status = WAITING_RUN_CONFIRM

ACCEPT RUN (Issuing):
  Issuing window → POST /ptws/run {response: true}
  → ptwDb.runAcceptPTW → running_status = RUNNING
  → for each isolation: ActiveIsolation.linkPTW() → isoDB.updateIsolation (upsert)

REJECT RUN (Issuing):
  Issuing window → POST /ptws/run {response: false}
  → ptwDb.runRejectPTW → running_status = NOT_RUNNING

REQUEST HOLD:
  Performer → POST /ptws/hold-request {keep-tags: [...]}
  → ptwDb.requestToHldPTW → running_status = WAITING_HLD_CONFIRM
  → keep_isolations stored on PTW

ACCEPT HOLD (Issuing):
  Issuing window → POST /ptws/hold {response: true}
  → ptwDb.hldAcceptPTW → running_status = HELD (approval_status stays APPROVED)
  → isolations NOT in keep_isolations: ActiveIsolation.unlinkPTW()

REJECT HOLD (Issuing):
  Issuing window → POST /ptws/hold {response: false}
  → ptwDb.hldRejectPTW → running_status = RUNNING (restored)

REQUEST CLOSE:
  Performer → POST /ptws/close-request
  → ptwDb.requestToClsPTW → running_status = WAITING_CLS_CONFIRM

ACCEPT CLOSE (Issuing):
  Issuing window → POST /ptws/close {response: true}
  → ptwDb.clsAcceptPTW → running_status = CLOSED
  → all isolations: ActiveIsolation.unlinkPTW()

REJECT CLOSE (Issuing):
  Issuing window → POST /ptws/close {response: false}
  → ptwDb.clsRejectPTW → running_status = RUNNING (restored)
